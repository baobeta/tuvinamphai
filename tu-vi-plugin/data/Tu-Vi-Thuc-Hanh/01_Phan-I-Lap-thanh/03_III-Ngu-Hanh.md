# III. Ngũ Hành

> Phần I – Lập thành  
> Trang sách 8–9 · *Tử Vi Thực Hành* (Dịch Lý Huyền Cơ)

Mộc - Hỏa - Thổ - Kim - Thủy

```
TƯƠNG KHẮC                          TƯƠNG SINH

Mộc khắc     Thổ                    Mộc      sinh   Hỏa
Thổ …        Thủy                   Hỏa      …      Thổ
Thủy …       Hỏa                    Thỏ      …      Kim
Hỏa …        Kim                    Kim      …      Thủy
Kim …        Mộc                    Thủy     …      Mộc
PHÂN BIỆT SINH – MỘ – TUYỆT

Tứ sinh là: Dần Thân Tỵ Hợi
Tứ mộ là:    Thìn Tuất Sửu Mùi
```

Tứ tuyệt là: Tý Ngọ Mão Dậu  
Cách chia nhóm trên đây rất cần thiết khi an sao đoán mệnh để biết sao nào đi vào nhóm nào có liên quan đến sự hay, dở.

### Tam Hợp

```
Dần Ngọ Tuất        hóa   HỎA
Thân Tý Thìn              THỦY
Tỵ Dậu Sửu                KIM
Hợi Mão Mùi               MỘC
```

Và khi đoán số phải lấy Tam hợp để phối kiểm các sao.

```
NHỊ HỢP                               NHỊ XUNG

Tý      hợp      Sửu                  Tý     xung Ngọ
Dần ...          Hợi                  Mão ...         Mùi
Mão ...          Tuất                 Dần ...         Thân
Thìn ...         Dậu                  Tỵ  ...         Hợi
Tỵ      ...      Thân                 Thìn ...        Tuất
Ngọ     ...      Mùi                  Sửu ...         Mùi
```

Phân rõ xung hợp trên đây cũng cần cho việc phối hợp các sao khi đoán số.
